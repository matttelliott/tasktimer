# TaskTimer

- Create, execute, and complete timed tasks grouped into savable, repeatable, ordered routines and subroutines
- Install to iPhone home screen as PWA

TaskTimer is good for:

- Workout routines
- Household chores
- Cooking recipes
- Pomodoro cycles
- etc

## Task

- each task has its own duration
- active task counts down and sounds an alarm on duration completion
- an individual task is just like any other task on any other todo list. it can have a duration in seconds. duration input accepts basic math 60 * 5 = 5 minutes; (60 * 2) + 30 = 2 min 30 seconds; etc
- when a task countdown reaches zero, it ALWAYS sounds an alarm/alert/notification/makes the user aware AND begins counting up
- a task can have no duration, in which case it just counts up.
- task timers count correctly when host device/browser is asleep/locked

## Routine

- A routine is a saved, ordered, repeatable set of tasks
- Routines can be added to other routines as subroutines

## Subroutine

- A subroutine is a routine that has been added as a step in another routine
- Subroutines can be nested at any level up to X configurable limit
  - exmaple: Daily Routine includes Household Chores includes Clean Kitches includes Do Dishes
- Subroutines can be repeatable to Y repetitions
  - exmaple: 5 sets of (30 seconds push ups, 30 seconds break), 5 sets of (1 minute squats, 2 minute break)
